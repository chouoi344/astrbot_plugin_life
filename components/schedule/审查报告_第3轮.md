## 四、用户实机确认步骤

先在 AstrBot 中更新并重载这个插件，再进行下列检查，无需删除原有数据。

1. **直接看日程**：打开插件视图 → 今日日程。已有日程应立即显示；新业务日生成中应显示进度，并自动变成时间轴，无需先发指令。超过 3 分钟时应出现“生成时间比较长，可以稍后点刷新”。
2. **恢复当前失败的档案**：打开生活档案 → 点击“重新生成”。即使提示今日自动重试已用完，也应开始生成。按钮变为“正在生成中”，完成后自动出现档案。模型暂时不可用时，应出现中文原因和可再次点击的重试按钮。
3. **手动编辑档案**：在生活档案填写一项 → 保存修改。应显示已保存，旧的失败或次数耗尽提示消失；再刷新，填写内容仍在。
4. **确认正常社交内容**：查看生成的档案和日程。如果有家人、朋友之间的电话、视频、游戏，应正常保留；与自己的受限互动应被局部清除或替换，其他内容仍保留。
5. **检查设置即时生效**：进入基础设置，记下原值；修改城市后保存，应显示立即生效。清空城市会明确提示按季节模拟天气。主人 ID 可输入 `42 43，44` 这类分隔形式，保存后应成为多个 ID；正式使用时填自己的真实 ID。每日生成时间用时间选择器填写，修改后再恢复原值，日程应补齐相应窗口。
6. **检查北京时间与常驻更新**：电脑保持原来的 Pacific 时区，AstrBot 保持 Asia/Shanghai。查看时间轴，应按角色的北京时间高亮当前活动；停留跨过下一时间段后，应在约一分钟内更新。上海每日生成分界前后也应自动切换。
7. **检查切页与长任务**：日程或档案生成中切到衣柜，再切回来，内容应反映当前后台进度。关闭视图后重新打开，已完成任务应能看到结果。图片 AI 提取较慢时继续等待，应在实际模型结果或中文超时提示出现后恢复操作。

1. `core/domain.py` 的“语音通话”别名增加裸“语音”，覆盖“和你语音”“睡前和你语音”“给你发语音”“发条语音给你”“语音给主人”等表达。已安装用户保存的原 `forbidden_interactions` 列表可以直接使用；本轮未改默认列表或实机配置。
2. 沿用第 3 轮的用户指向、可选昵称和字段隔离规则。家人朋友的语音、语音输入/识别/转文字、独自录制备忘继续放行；明确发给用户的语音会拦截，包括“自己录条语音给你”。收件人放在语音词后的第三方表达也会正确识别。
3. 集中定义 `VOICE_MESSAGE_TERMS`、消息动作识别和 `RESTRICT_VOICE_MESSAGES`，与 `VOICE_CALL_TERMS` 分开。第 5 阶段支持语音消息后，将消息开关设为 False 即可同时调整过滤与提示词；实时通话、连麦仍按原限制处理。已用测试模拟这个入口，确认消息放开后通话仍受限。
4. `core/prompts.py` 增加共用语音边界，`core/engine.py` 的档案提示复用同一边界。档案、日程及其中的新长期事件、意外、聊天判断和聊天注入均明确：目前只用文字和图片，不安排、不承诺语音通话，也不发语音消息；用户提出时，用符合人设的理由自然带过。
5. 独立自查发现“给你发语音消息的安排已经取消”被新增裸别名误伤，已修复消息/通话类别尾词与后置取消的组合识别，并补上两条回归。原有的局部清理继续保留其他档案字段、句子和日程段。

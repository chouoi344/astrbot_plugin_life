# 自然语音 v0.1.9

让角色在私聊里发一条完整的语音。可以用 `[轻笑]`、`[耳语]` 等声音标签，也可以配合日程和主动消息使用。

## 可以在哪用

| 聊天方式 | 语音工具发出的内容 |
| --- | --- |
| OneBot QQ 私聊（兼容 OneBot 的自制机器人也可用） | 语音 |
| QQ 官方机器人私聊（WebSocket 或 Webhook） | 语音 |
| AstrBot 网页聊天 | 语音 |
| 个人微信 `weixin_oc` | 直接发台词文字，跳过语音生成和相应费用 |

QQ 官方使用机器人私聊消息接口，受账号的发送权限和回复额度限制。

## 安装和设置

需要 **AstrBot 4.26.0 或以上**、Python 3.10 或以上。

1. 在 AstrBot 插件管理中上传本插件 ZIP。
2. 打开“自然语音”设置，填写自己的 BreezeBlue 密钥并保存。
3. 重新打开设置，在“音色”下拉框选择名称并保存。
4. 在私聊中发送 `/life_voice_test [轻笑]我在听，你慢慢说。` 试听。
5. 对角色说“想听你发条语音”，即可测试模型调用。

下拉框读取该账号的“我的音色”。没有音色时，先到 BreezeBlue 创建或克隆，再保存插件设置刷新列表。升级会保留原来选择的音色；同名音色会附编号区分。

语音生成按服务规则计费。

| 设置 | 用途 |
| --- | --- |
| 启用自然语音 | 开启语音发送 |
| BreezeBlue 密钥 | 填写服务密钥 |
| 音色 | 按名称选择账号中的音色 |

旧 MiniMax 插件可以保留安装；使用新插件时关闭旧插件，两者的 `tts_speak` 工具不能同时启用。

## 使用方式

- 模型工具为 `tts_speak(text)`，沿用 MiniMax 的工具名和参数，原人设中的调用名称无需修改。
- 一次调用发送一条完整语音，不按标点或字数拆分。同一轮重复台词只发送一次。
- 台词可带 `[耳语]`、`[轻笑]` 等中文声音标签，每条最多两个。声音标签仅用于工具台词。
- 生成失败或 QQ 明确拒绝语音时，可改发完整正文。QQ 发送结果不明时结束本轮，避免收到重复内容。
- 仅支持私聊。模型需要支持工具调用，并启用 `tts_speak`。
- `/life_voice_status` 查看设置状态及最近错误。

## 配合生活日程

与拟人化生活日程 Plus v1.0.3 或以上共同启用时，模型可以参考当前活动、地点、心情和用户意愿选择语音。使用已有的生活上下文，不需要再配置角色或另一份日程。

成功发出的语音台词，以及失败后成功改发的文字，会交给日程插件判断是否包含新约定；声音标签不会进入约定正文。未送达的内容不算已经说过，普通“想听一句语音”不会仅因含有“语音”二字增加日程判断。

自然语音可独立发语音。主动消息插件负责调度时机，调用自然语音交付台词。

开发对接见[语音已发送正文协议](联动协议.md)。

## 声音参数

使用 `breeze-tts-2`、中文、MP3，`speed=1.0`、`guidance_scale=2.0`、`volume=1.0`、`use_speaker_boost=false`。正文使用声音标签，请求不传 `instructions`。

[文字转语音接口](https://docs.breezeblue.ai/api-reference/text-to-speech/convert-text-to-speech) · [声音标签](https://docs.breezeblue.ai/guides/audio-tags)

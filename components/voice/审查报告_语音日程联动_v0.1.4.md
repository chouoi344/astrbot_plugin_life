## 已检查的真实失败路径

| 情况 | 结果 |
| --- | --- |
| 发送仍在等待 | 暂无正文记录 |
| 语音成功 | 记录清理后正文，`medium=voice` |
| 合成失败或语音发送失败，正文回退成功 | 记录实际正文，`medium=text` |
| 所有发送失败 | 不追加记录，不将该正文标记为已交付 |
| 同事件并发重复、同事件不同正文、不同事件相同正文 | 分别去重、追加、保留独立交付 |
| 生成、语音发送、回退文字发送途中取消 | 三项内存实验均无新记录，活动任务清理；同事件重试成功后仅登记一次 |
| 日程消费者停用或被会话过滤 | 发送记录仍正常产生，消费者钩子不执行 |

记录只证明 `event.send()` 正常返回，不代表用户已收听；同一正文的 SHA256 不能用作跨事件去重键。消费者应沿用日程的主人、角色和会话限制，仅把实际正文交给既有判断流程。

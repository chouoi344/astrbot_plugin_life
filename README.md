# 拟人生活

让 QQ 里的角色按自己的日程过日子：聊天时带着当下的生活状态，会按你设定的节奏主动找你、关心你提到的事，还能发语音、自拍和 QQ 空间。

- **AstrBot**：≥ 4.26.0（按 4.29.0 的接口开发和测试）
- **Python**：≥ 3.10
- **平台**：QQ 个人号（NapCat / OneBot v11，`aiocqhttp`）、QQ 官方机器人私聊（`qq_official` / `qq_official_webhook`）、AstrBot 网页聊天（`webchat`，只用语音）
- **依赖**：见 `requirements.txt`，AstrBot 安装插件时会自动安装。代码还用到的 `botpy`、`mcp`、`yarl`、`packaging` 随 AstrBot 自带，不需要另装。

## 功能

| 功能 | 说明 |
| --- | --- |
| 生活日程 | 跟随 AstrBot 全局默认人设，生成生活档案、每天的日程、穿搭和心情。聊天时把当前时间、正在做的事、约定等写进本轮的 `<character_life>`（约 700 字，按重要程度取舍）。 |
| 主动聊天 | 按“最短～最长间隔”随机挑时间主动找你；免打扰时段内不发；连续没回复达到上限或当天次数用完就停。可以同时接管多条私聊，各自计数。 |
| 关心你的事 | 你提到“下午两点面试”这类有时间的事，会记下来，事后自然问一句结果；面板里可以查看和删除。回访时间由模型按事情长短定，在事情开始后 1～15 小时之间；到了回访时间 12 小时内没找到合适时机就不再问；还没到回访时间时不会提前拿来当话题。 |
| 想你了 | 有契机才想：角色自己的日程走到自然节点（一件事结束、下班、饭点、快睡觉时），或遇到和你们聊过的话题有关的事时，由模型按人设判断要不要说想你，消息会带出这个契机。每天最多一次；正在聊天（最短主动间隔内有过消息）或角色在忙、在睡觉时不会说。 |
| “等我忙完找你” | 你这样说之后，角色先不打扰；超过设定时长还没来，会自然问一句。 |
| 照片 | 自拍、全身照、食物、场景、组照和改图；场景、穿搭跟随日程。尺寸可在设置里选（默认 2K、3:4），服务不接受时自动降一档。 |
| 语音 | QQ 私聊和网页聊天里按需要发语音，可选音色；主动聊天也可以发语音。 |
| QQ 空间 | 跟着日程分享日常照片，回复管理员的评论。 |

装有 **LivingMemory** 时，主动消息会读取长期记忆。官方版 LivingMemory 没有“送达后记录”接口，这时主动消息不写入长期记忆（聊天记录照常保存），面板“私聊互动”会显示提示。

## 安装

1. 在 AstrBot 插件管理里上传插件 ZIP（或从仓库安装）。
2. 先配置好聊天模型和全局默认人设，再打开“拟人生活”的设置。
3. 打开“生活日程”，填好基本信息，点 **保存并关闭**。后台会准备生活档案和日程，进度在左侧 **拟人生活** 视图里看。

### 主动聊天

1. 在要接管的 QQ 私聊里发送 `/sid`，把返回的完整编号（`平台ID:FriendMessage:对方ID`）添加到“目标私聊”，可以添加多条。
2. 打开“启用自然私聊”并保存，然后在每条私聊里发一句普通消息，插件会自动识别机器人账号。
3. 按需调整主动间隔（默认 60～90 分钟）、免打扰时间（默认 1-7 点）、连续未回复上限（默认 2，0 为不限制）和每天最多次数（默认 5）。

你亲口要求的提醒（例如“明早 6 点叫我”）不受免打扰时段限制，也不计入每天次数和未回复次数，但角色需要那时有空。

### 照片、语音、QQ 空间

- **照片**：填写兼容 OpenAI Images 的服务地址（默认 `https://choupi.tech/v1/images/generations`）、API Key 和模型；到 **视图 → 照片 → 参考图库** 上传面部参考图，身材图选填。
- **语音**：填写服务 URL 和 API Key，保存后重新打开设置选择音色。服务 URL 默认 `https://choupi.tech`。
- **QQ 空间**：默认关闭，只能用 QQ 个人号。“说说参考私聊和记忆”默认关闭——说说对所有好友公开，打开后配文可能写到私聊里的事。

### QQ 官方机器人

先在 AstrBot 里接好 QQ 官方机器人。支持官方单聊，不接管官方群聊和频道；QQ 空间只能用个人号。主人用户 ID 填 `/sid` 返回的 **UID**（OpenID），目标私聊填同条回复里的完整 **UMO**。主动消息受 QQ 应用权限、接收方开关和频次限制，平台明确拒绝后会等对方发来新消息再试。发送限制以 [QQ 官方消息说明](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html) 为准。

## 指令和工具

| 指令 | 说明 |
| --- | --- |
| `/life` | 查看拟人生活状态 |
| `/查看日程`、`/日程原计划`、`/重写日程`、`/昨天` | 查看或重写日程 |
| `/查看档案`、`/重新生成档案`、`/档案已确认` | 生活档案 |
| `/查看约定`、`/取消约定` | 聊天里记下的约定 |
| `/查看衣柜`、`/展示` | 衣柜 |
| `/日程时间`、`/参考会话 [set/show/clear]` | 日程时间与主人的聊天来源 |
| `/life_photo_status` | 照片设置状态和最近问题 |
| `/life_voice_test [台词]`、`/life_voice_status` | 语音试听和状态 |

模型可用的工具：`life_get_schedule`、`life_wardrobe_*`、`photo_generate`、`tts_speak`、`qzone_*`。正常聊天即可，例如“发张你现在的自拍”“用语音跟我说晚安”。

## 主要设置

所有设置都在 AstrBot 的插件设置里，每项都有说明。常用的：

| 分区 | 设置 | 默认 |
| --- | --- | --- |
| 自然私聊 | 目标私聊、主动最短/最长间隔、免打扰时段、连续未回复上限、每天最多次数、主动语音/照片、参考的聊天条数、“等我忙完”最多等几小时、主动聊天提示词 | 60/90 分钟、1-7 点、2、5、20 条、6 小时、留空用内置 |
| 自然照片 | 服务地址、API Key、模型、照片尺寸 | `https://choupi.tech/v1/images/generations`、2K（3:4） |
| 自然语音 | 服务 URL、API Key、音色 | `https://choupi.tech` |
| QQ 空间 | 自己分享日常、每天最多几条、说说参考私聊和记忆、回复留言 | 开、2、关、开 |

网络请求会使用 AstrBot 设置里的代理（`http_proxy` / `no_proxy`）。照片和语音在插件载入时读取代理，改了 AstrBot 代理后需要重载本插件（保存一次本插件设置即可）才生效。

## 从 v1.3.x 升级

直接覆盖安装，保留 `astrbot_plugin_life` 的配置和数据即可，旧配置会自动迁移：

- 单条“要接管的私聊”自动并入“目标私聊”列表。
- 没改过的旧版主动提示词换成新的内置默认；改过的保留。
- 日程关键词是旧默认时，补上面试、考试、看病、体检、出差、答辩。
- “忙完再回”已删除：不再暂存忙时消息，角色忙或睡时照样回复（可能简短）。旧的 `data/plugin_data/astrbot_plugin_life_busy/pending.sqlite3` 和 `media/` 不再使用，可以手动删除。
- 说“晚安”不再暂停主动消息，改由免打扰时段控制。
- 照片默认尺寸从 4K 改为 2K，想保持原样可以把“照片尺寸”填成 `4K`。
- 生图服务地址、语音服务 URL 还是旧默认 `https://api.breeze.blue`（含 `/v1`、结尾斜杠、大小写等写法）时，自动换成新默认 choupi；自己填的其他地址不变。换地址后之前缓存的语音不再命中，再用到同一句会重新合成一次，旧缓存 7 天后自动清理。这项检查每个地址只在升级后第一次载入时做一次（不论是否换了地址，全新安装也一样），之后你自己填 BreezeBlue 不会再被改；想继续用 BreezeBlue 的，升级后把地址改回即可。

更新时不要先卸载插件，卸载时勾选“删除配置/数据”会清除档案和衣柜。

数据保存在 AstrBot 的 `data/plugin_data/` 下；语音缓存超过 7 天自动清理。日程生成、照片和语音会调用你配置的服务，按服务商计费。

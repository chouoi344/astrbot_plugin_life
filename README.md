# 拟人生活

让 QQ 里的角色按自己的日程生活：忙时晚点回复，空闲时分享新话题，还能发语音、自拍和 QQ 空间。

**AstrBot ≥ 4.26.0 · QQ 个人号（NapCat / OneBot v11）· AstrBot 网页聊天（语音）**

## 功能

| 功能 | 使用体验 |
| --- | --- |
| 日程与生活 | 跟随 AstrBot 全局默认人设，生成生活档案、日程、穿搭和心情，在视图查看日程和心情，管理档案与衣柜。 |
| 忙闲回复 | 看不了手机时暂存私聊，空闲后结合积压消息一起回复；轻忙时可能先简短告知。 |
| 主动聊天 | 有空、当天有尚未聊过的生活话题时再联系你；连续没得到回复会暂停。 |
| 照片 | 自拍、全身照、食物、场景、组照和改图；场景、穿搭跟随日程，表情结合当前心情和聊天。默认 3:4，可在聊天中指定比例。 |
| 语音 | 在 QQ 私聊和 AstrBot 网页聊天中按聊天需要发语音，可选择音色。QQ 私聊也可用于主动联系。 |
| QQ 空间 | 分享日常照片；发布后等下一段能看手机的空闲时间，最多分两轮查看当天说说的评论，只回复管理员新留言。 |

已安装 **LivingMemory** 时可联动记忆。记忆插件独立运行，不包含在本插件中。

## 快速开始

1. 在 AstrBot 插件管理中上传插件 ZIP。先配置聊天模型和全局默认人设，再打开“拟人生活”的设置。
2. 开启日程，填好基本信息，点击 **保存并关闭**。后台会准备生活档案和日程；从左侧 **拟人生活** 查看进度和结果。
3. 需要忙闲回复或主动聊天时，在目标 QQ 私聊发送 `/sid`，将返回的完整会话标识填进“要接管的私聊”，开启自然私聊并保存，再发一句普通消息完成账号识别。

照片、语音和 QQ 空间按需配置：

- **照片**：填写兼容 OpenAI Images 的服务地址、API Key 和模型；到 **视图 → 照片 → 参考图库** 上传面部参考图，身材图选填。
- **语音**：填写服务 URL 和 API Key，保存后重新打开设置选择音色。默认使用 BreezeBlue，其他地址需兼容同一语音接口；也可在视图中切换已加载的音色。
- **QQ 空间**：默认关闭，在插件设置中按需启用。使用当前 QQ 个人号发布和回评。

## 怎么用

正常聊天即可，例如：

> 发张你现在的自拍。  
> 给我看看今天的全身穿搭。  
> 用语音跟我说晚安。

在 QQ 私聊或 AstrBot 网页聊天发送 `/life_voice_test` 可以试听，发送 `/life_voice_status` 可以查看语音状态。

左侧视图提供 **今日概况、日程与生活、私聊互动、照片、语音、QQ 空间**。参考图可直接上传、替换、删除；最近成片会显示发送结果；私聊互动里可调整轻忙备用概率和补回等待时间，日程提供概率时优先跟随日程。

安静等待默认 **5 分钟**，仍需空闲且有新话题才会考虑主动联系。日程生成、照片和语音会调用配置的服务，费用按服务商计费。

## 升级

从整合版升级时，保留 `astrbot_plugin_life` 的配置和数据即可。从旧的独立日程、照片、语音、私聊、主动消息或 QQ 空间迁移时，先备份旧设置和数据、停用旧插件，再按分区填入设置并重载拟人生活。
